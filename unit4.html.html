React State Management - Complete Guide

1 Initial State
What is State?

State is data that changes over time within a component. It's like a component's memory that determines what it renders and how it behaves.

Key Points About Initial State:
  • State is initialized using useState hook
  • Can be any data type: number, string, boolean, object, array
  • Set once during component's first render
  • Private to the component (not accessible to others)
Example: Simple Counter with Initial State
Counter.jsx
import React, { useState } from 'react';

function Counter() {
  // useState returns [currentValue, updaterFunction]
  // Initial state is 0
  const [count, setCount] = useState(0);
  
  return (
    <div className="card">
      <div className="card-body text-center">
        <h2>Count: {count}</h2>
        <button 
          className="btn btn-primary"
          onClick={() => setCount(count + 1)}
        >
          Increment
        </button>
      </div>
    </div>
  );
}

export default Counter;
Initial Render: Count: 0 After Click: Count: 1 After Click: Count: 2

2 Async State Initialization (Lazy Initialization)
What is Lazy Initialization?

When initial state requires expensive computation, pass a function to useState. This function runs only once during initial render.

Example: Lazy Initialization
LazyInit.jsx
import React, { useState } from 'react';

function expensiveCalculation() {
  console.log('Running expensive calculation...');
  let sum = 0;
  for (let i = 0; i < 1000000; i++) {
    sum += i;
  }
  return sum;
}

function LazyInit() {
  // ❌ BAD: Runs on every render
  const [value1] = useState(expensiveCalculation());
  
  // ✅ GOOD: Runs only on initial render
  const [value2] = useState(() => expensiveCalculation());
  
  // Reading from localStorage
  const [settings] = useState(() => {
    const saved = localStorage.getItem('settings');
    return saved ? JSON.parse(saved) : { theme: 'light' };
  });
  
  return <div>Value: {value2}</div>;
}
Use lazy initialization when:
  • Reading from localStorage/sessionStorage
  • Complex calculations
  • Creating large data structures
3 Updating State
How to Update State?

State updates trigger re-renders. Use setter function from useState.

When new state depends on previous state, ALWAYS use functional update form to avoid stale state bugs!
Example: Direct vs Functional Updates
StateUpdate.jsx
import React, { useState } from 'react';

function StateUpdate() {
  const [count, setCount] = useState(0);
  
  // ❌ RISKY: Direct update
  const incrementDirect = () => {
    setCount(count + 1);
  };
  
  // ✅ SAFE: Functional update
  const incrementFunctional = () => {
    setCount(prevCount => prevCount + 1);
  };
  
  // Problem with direct updates
  const incrementByThree = () => {
    setCount(count + 1); // Only adds 1!
    setCount(count + 1);
    setCount(count + 1);
  };
  
  // Correct multiple updates
  const incrementByThreeCorrect = () => {
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
  };
  
  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={incrementFunctional}>+1</button>
      <button onClick={incrementByThreeCorrect}>+3</button>
    </div>
  );
}
Example: Updating Objects and Arrays
ComplexUpdate.jsx
import React, { useState } from 'react';

function ComplexUpdate() {
  const [user, setUser] = useState({
    name: 'Alice',
    age: 25,
    address: { city: 'Mumbai' }
  });
  
  const [tasks, setTasks] = useState(['Task 1', 'Task 2']);
  
  // Update nested object
  const updateCity = () => {
    setUser(prev => ({
      ...prev,
      address: {
        ...prev.address,
        city: 'Delhi'
      }
    }));
  };
  
  // Add to array
  const addTask = () => {
    setTasks(prev => [...prev, `Task ${prev.length + 1}`]);
  };
  
  // Remove from array
  const removeTask = (index) => {
    setTasks(prev => prev.filter((_, i) => i !== index));
  };
  
  return (
    <div>
      <p>{user.name}, {user.address.city}</p>
      <button onClick={updateCity}>Move to Delhi</button>
      
      <ul>
        {tasks.map((task, i) => (
          <li key={i}>
            {task}
            <button onClick={() => removeTask(i)}>Remove</button>
          </li>
        ))}
      </ul>
      <button onClick={addTask}>Add Task</button>
    </div>
  );
}
Rules for Updating State:
  • Never mutate state directly
  • Always create new object/array
  • Use spread operator (...)
  • For arrays: use map, filter, concat
4 Lifting State Up
What is Lifting State Up?

When multiple components need to share state, move it to their closest common parent.

Example: Temperature Converter
TemperatureInput.jsx (Child)
import React from 'react';

function TemperatureInput({ scale, temperature, onChange }) {
  const scaleNames = { c: 'Celsius', f: 'Fahrenheit' };
  
  return (
    <div>
      <label>{scaleNames[scale]}:</label>
      <input 
        type="number"
        value={temperature}
        onChange={(e) => onChange(e.target.value)}
      />
    </div>
  );
}

export default TemperatureInput;
Calculator.jsx (Parent)
import React, { useState } from 'react';
import TemperatureInput from './TemperatureInput';

function toCelsius(f) { return ((f - 32) * 5) / 9; }
function toFahrenheit(c) { return (c * 9) / 5 + 32; }

function Calculator() {
  const [temperature, setTemperature] = useState('');
  const [scale, setScale] = useState('c');
  
  const handleCelsiusChange = (temp) => {
    setScale('c');
    setTemperature(temp);
  };
  
  const handleFahrenheitChange = (temp) => {
    setScale('f');
    setTemperature(temp);
  };
  
  const celsius = scale === 'f' ? toCelsius(temperature) : temperature;
  const fahrenheit = scale === 'c' ? toFahrenheit(temperature) : temperature;
  
  return (
    <div>
      <TemperatureInput 
        scale="c" 
        temperature={celsius}
        onChange={handleCelsiusChange}
      />
      
      <TemperatureInput 
        scale="f" 
        temperature={fahrenheit}
        onChange={handleFahrenheitChange}
      />
    </div>
  );
}

5 Event Handling
Event Handling in React

React events use camelCase and you pass functions as handlers.

Example: Common Events
Events.jsx
import React, { useState } from 'react';

function Events() {
  const [text, setText] = useState('');
  const [submitted, setSubmitted] = useState('');
  
  // Click event
  const handleClick = () => {
    alert('Button clicked!');
  };
  
  // Click with parameter
  const greet = (name) => {
    alert(`Hello, ${name}!`);
  };
  
  // Change event
  const handleChange = (e) => {
    setText(e.target.value);
  };
  
  // Submit event
  const handleSubmit = (e) => {
    e.preventDefault(); // Prevent page reload
    setSubmitted(text);
    setText('');
  };
  
  return (
    <div>
      {/* Click Events */}
      <button onClick={handleClick}>Click Me</button>
      <button onClick={() => greet('Student')}>Greet</button>
      
      {/* Form Events */}
      <form onSubmit={handleSubmit}>
        <input 
          type="text"
          value={text}
          onChange={handleChange}
          placeholder="Type something"
        />
        <button type="submit">Submit</button>
      </form>
      
      {submitted && <p>Submitted: {submitted}</p>}
    </div>
  );
}
Event When It Fires Example
onClick Element is clicked <button onClick={fn}>
onChange Input value changes <input onChange={fn}>
onSubmit Form is submitted <form onSubmit={fn}>
onMouseEnter Mouse enters element <div onMouseEnter={fn}>
onKeyPress Key is pressed <input onKeyPress={fn}>

Components that don't manage their own state. They only receive props and render UI.

Example: State vs Props
Example.jsx
import React, { useState } from 'react';

// Child component receives props
function Child({ name, age }) {
  // Cannot modify props!
  // name = 'New Name'; // ❌ Error!
  
  return <p>{name} is {age} years old</p>;
}

// Parent component manages state
function Parent() {
  const [name, setName] = useState('John');
  const [age, setAge] = useState(25);
  
  return (
    <div>
      {/* Passing state as props */}
      <Child name={name} age={age} />
      
      {/* Can modify state */}
      <button onClick={() => setAge(age + 1)}>
        Increase Age
      </button>
    </div>
  );
}

9 Component Communication
How Components Communicate

Data flows DOWN via props, Events flow UP via callbacks.

Example: Parent-Child Communication
Communication.jsx
import React, { useState } from 'react';

// Child component
function Child({ message, onSend }) {
  const [input, setInput] = useState('');
  
  const handleSend = () => {
    onSend(input); // Send data UP to parent
    setInput('');
  };
  
  return (
    <div>
      <p>From parent: {message}</p>
      <input 
        value={input}
        onChange={(e) => setInput(e.target.value)}
      />
      <button onClick={handleSend}>Send to Parent</button>
    </div>
  );
}

// Parent component
function Parent() {
  const [parentMsg, setParentMsg] = useState('Hello from Parent');
  const [childMsg, setChildMsg] = useState('');
  
  const handleReceive = (msg) => {
    setChildMsg(msg); // Receive data from child
  };
  
  return (
    <div>
      <h3>Parent Component</h3>
      <p>From child: {childMsg}</p>
      
      {/* Pass data DOWN and callback UP */}
      <Child 
        message={parentMsg}
        onSend={handleReceive}
      />
    </div>
  );
}

Express.js - Web Framework

1 Introduction to Express
What is Express?

Express is a minimal and flexible Node.js web framework for building web applications and APIs.

Why Express?
  • Fast and minimalist
  • Powerful routing
  • Middleware support
  • Large ecosystem
Example: Basic Express Server
server.js
const express = require('express');
const app = express();

// Middleware to parse JSON
app.use(express.json());

// Root route
app.get('/', (req, res) => {
  res.send('Hello World!');
});

// JSON API route
app.get('/api/info', (req, res) => {
  res.json({
    message: 'Express Server',
    version: '1.0.0',
    timestamp: new Date()
  });
});

// Start server
const PORT = 3000;
app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
$ node server.js Server running on http://localhost:3000
Example: Middleware
middleware.js
const express = require('express');
const app = express();

// Built-in middleware
app.use(express.json());

// Custom middleware - Logger
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next(); // Pass to next middleware
});

// Custom middleware - Auth
const auth = (req, res, next) => {
  const token = req.headers['authorization'];
  
  if (token === 'secret-token') {
    next(); // Authenticated
  } else {
    res.status(401).json({ error: 'Unauthorized' });
  }
};

// Protected route
app.get('/api/protected', auth, (req, res) => {
  res.json({ message: 'Protected data' });
});

// Public route
app.get('/api/public', (req, res) => {
  res.json({ message: 'Public data' });
});

app.listen(3000);

2 Express Router
Modular Routes

Use Router to organize routes into separate files.

Example: Router
routes/users.js
const express = require('express');
const router = express.Router();

let users = [
  { id: 1, name: 'John' },
  { id: 2, name: 'Jane' }
];

// GET all users
router.get('/', (req, res) => {
  res.json(users);
});

// GET user by ID
router.get('/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  if (!user) {
    return res.status(404).json({ error: 'User not found' });
  }
  res.json(user);
});

// POST create user
router.post('/', (req, res) => {
  const newUser = {
    id: users.length + 1,
    name: req.body.name
  };
  users.push(newUser);
  res.status(201).json(newUser);
});

// DELETE user
router.delete('/:id', (req, res) => {
  users = users.filter(u => u.id !== parseInt(req.params.id));
  res.json({ message: 'User deleted' });
});

module.exports = router;

REST API - Architectural Style

1 REST API Fundamentals
What is REST?

REST (Representational State Transfer) is an architectural style using HTTP methods for CRUD operations.

REST Principles:
  • Client-Server separation
  • Stateless communication
  • Cacheable responses
  • Uniform interface
  • Resource-based URLs

HTTP Methods (CRUD)

Method CRUD Purpose Example URL
GET Read Retrieve resource(s) GET /api/users
POST Create Create new resource POST /api/users
PUT Update Replace entire resource PUT /api/users/1
PATCH Update Partial update PATCH /api/users/1
DELETE Delete Remove resource DELETE /api/users/1
Example: Complete REST API
api/students.js
const express = require('express');
const router = express.Router();

let students = [
  { id: 1, name: 'Aarav', course: 'BCA', cgpa: 8.5 },
  { id: 2, name: 'Diya', course: 'BCA', cgpa: 9.1 }
];

// GET all students
router.get('/', (req, res) => {
  res.json({
    success: true,
    count: students.length,
    data: students
  });
});

// GET student by ID
router.get('/:id', (req, res) => {
  const student = students.find(s => s.id === parseInt(req.params.id));
  
  if (!student) {
    return res.status(404).json({
      success: false,
      error: 'Student not found'
    });
  }
  
  res.json({
    success: true,
    data: student
  });
});

// POST create student
router.post('/', (req, res) => {
  const { name, course, cgpa } = req.body;
  
  if (!name || !course) {
    return res.status(400).json({
      success: false,
      error: 'Name and course required'
    });
  }
  
  const newStudent = {
    id: students.length + 1,
    name,
    course,
    cgpa: cgpa || 0
  };
  
  students.push(newStudent);
  
  res.status(201).json({
    success: true,
    data: newStudent
  });
});

// PUT update student
router.put('/:id', (req, res) => {
  const student = students.find(s => s.id === parseInt(req.params.id));
  
  if (!student) {
    return res.status(404).json({
      success: false,
      error: 'Student not found'
    });
  }
  
  student.name = req.body.name || student.name;
  student.course = req.body.course || student.course;
  student.cgpa = req.body.cgpa || student.cgpa;
  
  res.json({
    success: true,
    data: student
  });
});

// DELETE student
router.delete('/:id', (req, res) => {
  const index = students.findIndex(s => s.id === parseInt(req.params.id));
  
  if (index === -1) {
    return res.status(404).json({
      success: false,
      error: 'Student not found'
    });
  }
  
  students.splice(index, 1);
  
  res.json({
    success: true,
    message: 'Student deleted'
  });
});

module.exports = router;

GraphQL - Query Language for APIs

1 Introduction to GraphQL
What is GraphQL?

GraphQL is a query language for APIs that lets clients request exactly the data they need.

GraphQL Features:
  • Field Specification: Ask for exactly what you need
  • Graph Based: Follow relationships easily
  • Single Endpoint: One URL for all operations
  • Strongly Typed: Schema defines all types
  • Introspection: Query the schema itself

GraphQL vs REST

Feature REST GraphQL
Endpoints Multiple (/users, /posts) Single (/graphql)
Data Fetching Fixed structure Client specifies fields
Over-fetching ❌ Common ✅ No over-fetching
Under-fetching ❌ Multiple requests ✅ Single request
Type System Not built-in ✅ Strongly typed

    deleteStudent(id: ID!): Boolean!
  }
  
  input CreateStudentInput {
    name: String!
    email: String!
    courseId: ID!
    cgpa: Float
  }
  
  input UpdateStudentInput {
    name: String
    email: String
    cgpa: Float
  }
`;

// Resolvers
const resolvers = {
  Query: {
    students: () => students,
    student: (parent, args) => students.find(s => s.id === args.id),
    courses: () => courses
  },
  
  Mutation: {
    createStudent: (parent, args) => {
      const newStudent = {
        id: String(students.length + 1),
        ...args.input
      };
      students.push(newStudent);
      return newStudent;
    },
    
    updateStudent: (parent, args) => {
      const student = students.find(s => s.id === args.id);
      if (!student) throw new Error('Student not found');
      
      Object.assign(student, args.input);
      return student;
    },
    
    deleteStudent: (parent, args) => {
      const index = students.findIndex(s => s.id === args.id);
      if (index === -1) return false;
      
      students.splice(index, 1);
      return true;
    }
  },
  
  Student: {
    course: (parent) => courses.find(c => c.id === parent.courseId)
  },
  
  Course: {
    students: (parent) => students.filter(s => s.courseId === parent.id)
  }
};

// Create server
const server = new ApolloServer({ typeDefs, resolvers });

server.listen(4000).then(({ url }) => {
  console.log(`🚀 GraphQL Server ready at ${url}`);
});

const resolvers = {
  Mutation: {
    createStudent: (parent, args) => {
      const { name, email, courseId, cgpa } = args.input;
      
      // Input validations
      if (!name || name.trim().length === 0) {
        throw new Error('Name is required');
      }
      
      if (!email || !email.includes('@')) {
        throw new Error('Valid email is required');
      }
      
      if (cgpa && (cgpa < 0 || cgpa > 10)) {
        throw new Error('CGPA must be between 0 and 10');
      }
      
      // Check if course exists
      const course = courses.find(c => c.id === courseId);
      if (!course) {
        throw new Error('Course not found');
      }
      
      // Create student
      const newStudent = {
        id: String(students.length + 1),
        name: name.trim(),
        email: email.toLowerCase(),
        courseId,
        cgpa: cgpa || 0
      };
      
      students.push(newStudent);
      return newStudent;
    }
  }
};

import React, { useState } from 'react';
import { useMutation, gql } from '@apollo/client';

const CREATE_STUDENT = gql`
  mutation CreateStudent($input: CreateStudentInput!) {
    createStudent(input: $input) {
      id
      name
      email
      cgpa
    }
  }
`;

function CreateStudent() {
  const [formData, setFormData] = useState({
    name: '',
    email: '',
    courseId: '1',
    cgpa: 0
  });
  
  const [createStudent, { loading, error, data }] = useMutation(CREATE_STUDENT, {
    refetchQueries: ['GetStudents'] // Refresh list after creation
  });
  
  const handleChange = (e) => {
    setFormData({
      ...formData,
      [e.target.name]: e.target.value
    });
  };
  
  const handleSubmit = (e) => {
    e.preventDefault();
    
    createStudent({
      variables: {
        input: {
          name: formData.name,
          email: formData.email,
          courseId: formData.courseId,
          cgpa: parseFloat(formData.cgpa)
        }
      }
    });
  };
  
  return (
    <div>
      <h3>Create New Student</h3>
      <form onSubmit={handleSubmit}>
        <input
          name="name"
          value={formData.name}
          onChange={handleChange}
          placeholder="Name"
          required
        />
        <input
          name="email"
          type="email"
          value={formData.email}
          onChange={handleChange}
          placeholder="Email"
          required
        />
        <input
          name="cgpa"
          type="number"
          step="0.1"
          value={formData.cgpa}
          onChange={handleChange}
          placeholder="CGPA"
        />
        <button type="submit" disabled={loading}>
          {loading ? 'Creating...' : 'Create Student'}
        </button>
      </form>
      
      {error && <p style={{color: 'red'}}>Error: {error.message}</p>}
      {data && <p style={{color: 'green'}}>Created: {data.createStudent.name}</p>}
    </div>
  );
}
