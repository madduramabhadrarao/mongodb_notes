1. MongoDB Basics

Understanding the fundamentals of MongoDB

What is MongoDB?

MongoDB is a NoSQL document database that stores data in flexible, JSON-like documents. It's designed for scalability, performance, and ease of development.

Key Features:

  • Document-Oriented: Data stored as BSON (Binary JSON) documents
  • Schema-less: Flexible schema design
  • Scalable: Horizontal scaling through sharding
  • High Performance: Optimized for read/write operations
  • Rich Query Language: Powerful querying capabilities
Note: MongoDB is especially suitable for applications with rapidly changing requirements or unstructured data.

2. Documents

Understanding MongoDB's data structure

What is a Document?

A document is a record in MongoDB, similar to a row in relational databases. Documents are stored in BSON format and can contain nested structures.

Document Example:

{ "_id": ObjectId("507f1f77bcf86cd799439011"), "name": "John Doe", "age": 30, "email": "john@example.com", "address": { "street": "123 Main St", "city": "New York", "zipcode": "10001" }, "hobbies": ["reading", "gaming", "coding"], "createdAt": ISODate("2024-01-15T10:30:00Z") }

Document Characteristics:

  • _id field: Unique identifier (auto-generated if not provided)
  • Field-value pairs: Similar to JSON objects
  • Nested documents: Documents can contain other documents
  • Arrays: Can store multiple values
  • Maximum size: 16MB per document

BSON Data Types:

Type Description Example
String UTF-8 string "Hello World"
Number Integer or Float 42, 3.14
Boolean true/false true
Object Embedded document { key: "value" }
Array List of values [1, 2, 3]
ObjectId Unique identifier ObjectId("...")
Date Date and time ISODate("2024-01-15")
Null Null value null

3. Collections

Grouping documents together

What is a Collection?

A collection is a group of MongoDB documents, similar to a table in relational databases. Collections don't enforce a schema by default.

Creating Collections:

// Explicit creation db.createCollection("users") // Implicit creation (created when first document is inserted) db.users.insertOne({ name: "Alice" }) // With options db.createCollection("logs", { capped: true, size: 5242880, max: 5000 })

Collection Operations:

// List all collections show collections // Drop a collection db.users.drop() // Rename a collection db.users.renameCollection("customers") // Get collection stats db.users.stats()
Tip: Collection names should be descriptive and follow naming conventions (lowercase, plural form).

4. Databases

Organizing collections into databases

MongoDB Databases

A database is a container for collections. Each database has its own set of files on the file system.

Database Operations:

// Show all databases show dbs // Switch to a database (creates if doesn't exist) use myDatabase // Show current database db // Drop database db.dropDatabase() // Get database stats db.stats()

Reserved Database Names:

  • admin: Administrative database
  • local: Stores data for replication
  • config: Sharding configuration data

5. MongoDB Query Language

Powerful querying capabilities

Query Operators

Comparison Operators:

// Equal to db.users.find({ age: 30 }) // Greater than db.users.find({ age: { $gt: 25 } }) // Greater than or equal db.users.find({ age: { $gte: 25 } }) // Less than db.users.find({ age: { $lt: 40 } }) // Less than or equal db.users.find({ age: { $lte: 40 } }) // Not equal db.users.find({ age: { $ne: 30 } }) // In array db.users.find({ age: { $in: [25, 30, 35] } }) // Not in array db.users.find({ age: { $nin: [25, 30, 35] } })

Logical Operators:

// AND db.users.find({ age: { $gt: 25 }, city: "New York" }) // OR db.users.find({ $or: [ { age: { $lt: 25 } }, { age: { $gt: 60 } } ] }) // NOT db.users.find({ age: { $not: { $gt: 30 } } }) // NOR db.users.find({ $nor: [ { age: { $lt: 25 } }, { status: "inactive" } ] })

Element Operators:

// Check if field exists db.users.find({ email: { $exists: true } }) // Check field type db.users.find({ age: { $type: "number" } })

Array Operators:

// Match all elements db.users.find({ hobbies: { $all: ["reading", "gaming"] } }) // Match array size db.users.find({ hobbies: { $size: 3 } }) // Match any element db.users.find({ "hobbies": "reading" }) // Element match db.users.find({ hobbies: { $elemMatch: { $eq: "reading" } } })

8. MongoDB CRUD Operations

Create, Read, Update, Delete operations

Create Operations

Insert One Document:

db.users.insertOne({ name: "Alice Johnson", email: "alice@example.com", age: 28, role: "developer", skills: ["JavaScript", "Python", "MongoDB"] }) // Response { acknowledged: true, insertedId: ObjectId("...") }

Insert Multiple Documents:

db.users.insertMany([ { name: "Bob Smith", email: "bob@example.com", age: 35, role: "manager" }, { name: "Carol White", email: "carol@example.com", age: 30, role: "designer" } ]) // Response { acknowledged: true, insertedIds: { '0': ObjectId("..."), '1': ObjectId("...") } }

Insert with Options:

db.users.insertMany( [ { name: "User1", email: "user1@example.com" }, { name: "User2", email: "user2@example.com" } ], { ordered: false } // Continue on error )

Read Operations

Find Documents:

// Find all documents db.users.find() // Find with query db.users.find({ age: { $gt: 25 } }) // Find one document db.users.findOne({ name: "Alice Johnson" }) // Pretty print db.users.find().pretty() // Count documents db.users.countDocuments() db.users.countDocuments({ role: "developer" })

Query Methods:

// Limit results db.users.find().limit(5) // Skip documents db.users.find().skip(10) // Sort results db.users.find().sort({ age: 1 }) // Ascending db.users.find().sort({ age: -1 }) // Descending // Combine methods db.users.find() .sort({ age: -1 }) .limit(10) .skip(5)

Projection (Select Fields):

// Include specific fields db.users.find( {}, { name: 1, email: 1 } ) // Exclude specific fields db.users.find( {}, { password: 0, _id: 0 } ) // Include and exclude db.users.find( { age: { $gt: 25 } }, { name: 1, email: 1, _id: 0 } ) // Array element projection db.users.find( {}, { name: 1, skills: { $slice: 2 } } // First 2 skills )

Advanced Queries:

// Regex search db.users.find({ name: { $regex: /^Alice/, $options: 'i' } }) // Text search (requires text index) db.users.find({ $text: { $search: "developer javascript" } }) // Nested document query db.users.find({ "address.city": "New York" }) // Array contains db.users.find({ skills: "JavaScript" }) // Multiple array conditions db.users.find({ skills: { $all: ["JavaScript", "MongoDB"] } })

Update Operations

Update One Document:

db.users.updateOne( { name: "Alice Johnson" }, { $set: { age: 29, updatedAt: new Date() } } ) // Response { acknowledged: true, matchedCount: 1, modifiedCount: 1 }

Update Many Documents:

db.users.updateMany( { role: "developer" }, { $set: { department: "Engineering" } } )

Update Operators:

// Set field value db.users.updateOne( { name: "Alice" }, { $set: { status: "active" } } ) // Increment numeric field db.users.updateOne( { name: "Alice" }, { $inc: { loginCount: 1 } } ) // Multiply numeric field db.users.updateOne( { name: "Alice" }, { $mul: { salary: 1.1 } } ) // Rename field db.users.updateOne( { name: "Alice" }, { $rename: { "email": "emailAddress" } } ) // Remove field db.users.updateOne( { name: "Alice" }, { $unset: { tempField: "" } } ) // Set minimum value db.users.updateOne( { name: "Alice" }, { $min: { age: 25 } } ) // Set maximum value db.users.updateOne( { name: "Alice" }, { $max: { age: 30 } } ) // Set current date db.users.updateOne( { name: "Alice" }, { $currentDate: { lastModified: true } } )

Array Update Operators:

// Add to array db.users.updateOne( { name: "Alice" }, { $push: { skills: "React" } } ) // Add multiple to array db.users.updateOne( { name: "Alice" }, { $push: { skills: { $each: ["Vue", "Angular"] } } } ) // Add unique to array db.users.updateOne( { name: "Alice" }, { $addToSet: { skills: "TypeScript" } } ) // Remove from array db.users.updateOne( { name: "Alice" }, { $pull: { skills: "jQuery" } } ) // Remove first/last element db.users.updateOne( { name: "Alice" }, { $pop: { skills: 1 } } // 1 for last, -1 for first ) // Remove multiple items db.users.updateOne( { name: "Alice" }, { $pullAll: { skills: ["jQuery", "Backbone"] } } )

Upsert (Update or Insert):

db.users.updateOne( { email: "newuser@example.com" }, { $set: { name: "New User", createdAt: new Date() } }, { upsert: true } )

Replace One Document:

db.users.replaceOne( { name: "Alice" }, { name: "Alice Johnson", email: "alice.johnson@example.com", age: 29, role: "senior developer" } )

Delete Operations

Delete One Document:

db.users.deleteOne({ name: "Alice Johnson" }) // Response { acknowledged: true, deletedCount: 1 }

Delete Many Documents:

// Delete all matching documents db.users.deleteMany({ status: "inactive" }) // Delete all documents db.users.deleteMany({})

Find and Delete:

// Find and delete, returns deleted document db.users.findOneAndDelete( { name: "Alice" }, { sort: { age: -1 }, projection: { name: 1, email: 1 } } )

9. Aggregation Framework

Advanced data processing and analysis

Aggregation Pipeline

The aggregation framework processes data through a pipeline of stages.

Basic Aggregation:

// Simple aggregation db.orders.aggregate([ { $match: { status: "completed" } }, { $group: { _id: "$customerId", totalAmount: { $sum: "$amount" }, orderCount: { $sum: 1 } } }, { $sort: { totalAmount: -1 } } ])

Aggregation Stages:

// $match - Filter documents { $match: { age: { $gte: 18 } } } // $group - Group by field { $group: { _id: "$department", avgSalary: { $avg: "$salary" }, count: { $sum: 1 } } } // $project - Select/reshape fields { $project: { name: 1, email: 1, fullName: { $concat: ["$firstName", " ", "$lastName"] } } } // $sort - Sort documents { $sort: { age: -1, name: 1 } } // $limit - Limit results { $limit: 10 } // $skip - Skip documents { $skip: 20 } // $unwind - Deconstruct array { $unwind: "$skills" } // $lookup - Join collections { $lookup: { from: "departments", localField: "deptId", foreignField: "_id", as: "department" } } // $addFields - Add new fields { $addFields: { totalScore: { $add: ["$math", "$science"] } } } // $count - Count documents { $count: "totalUsers" } // $out - Write results to collection { $out: "aggregation_results" }

Complex Aggregation Example:

db.orders.aggregate([ // Stage 1: Filter by date range { $match: { orderDate: { $gte: ISODate("2024-01-01"), $lt: ISODate("2024-12-31") } } }, // Stage 2: Unwind items array { $unwind: "$items" }, // Stage 3: Group by product { $group: { _id: "$items.productId", totalQuantity: { $sum: "$items.quantity" }, totalRevenue: { $sum: { $multiply: ["$items.quantity", "$items.price"] } }, orderCount: { $sum: 1 } } }, // Stage 4: Lookup product details { $lookup: { from: "products", localField: "_id", foreignField: "_id", as: "productInfo" } }, // Stage 5: Unwind product info { $unwind: "$productInfo" }, // Stage 6: Project final shape { $project: { productName: "$productInfo.name", category: "$productInfo.category", totalQuantity: 1, totalRevenue: 1, avgOrderValue: { $divide: ["$totalRevenue", "$orderCount"] } } }, // Stage 7: Sort by revenue { $sort: { totalRevenue: -1 } }, // Stage 8: Limit to top 10 { $limit: 10 } ])

Accumulator Operators:

// Sum { $sum: "$amount" } // Average { $avg: "$score" } // Min/Max { $min: "$price" } { $max: "$price" } // First/Last { $first: "$status" } { $last: "$status" } // Push (create array) { $push: "$item" } // Add to set (unique array) { $addToSet: "$category" } // Standard deviation { $stdDevPop: "$score" } { $stdDevSamp: "$score" }

Installation:

Basic Connection:

Error Handling:

// Try-catch with async/await try { const user = await User.create({ name: 'John' }); console.log('User created:', user); } catch (error) { if (error.name === 'ValidationError') { console.error('Validation failed:', error.errors); } else if (error.code === 11000) { console.error('Duplicate key error:', error.keyValue); } else { console.error('Unexpected error:', error); } } // Global error handler mongoose.connection.on('error', (err) => { console.error('MongoDB connection error:', err); }); // Express error middleware app.use((err, req, res, next) => { console.error(err.stack); if (err.name === 'ValidationError') { return res.status(400).json({ error: 'Validation Error', details: err.errors }); } if (err.name === 'CastError') { return res.status(400).json({ error: 'Invalid ID format' }); } res.status(500).json({ error: 'Internal Server Error' }); });

Common Issues and Solutions:

Issue Solution
Connection timeout Check MongoDB service, network, firewall settings
Duplicate key error Check unique indexes, handle error in code
Validation errors Review schema validation rules
Slow queries Add indexes, optimize queries, use explain()
Memory issues Use pagination, limit(), lean()
Stale connections Implement connection retry logic
Best Practices:
  • Always use connection pooling
  • Implement proper error handling
  • Use indexes for frequently queried fields
  • Monitor query performance regularly
  • Use lean() for read-only operations
  • Implement request logging
  • Use transactions for critical operations
